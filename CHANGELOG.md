# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0-mvp] - 2026-01-26

### Added
- User authentication system with JWT
- 5-day trial implementation
- Personalized roadmap generation algorithm
- Professional dashboard UI
- Subject-wise hour allocation
- Phase-based planning (Foundation/Building/Revision)
- Trial countdown badge
- Delete roadmap functionality
- CreateRoadmap form
- UpgradePage for trial expiry

### Changed
- Tailwind CSS downgrade to v3 for stability
- Improved login/register UI
- Backend route structure (`/api/roadmaps`)

### Fixed
- Roadmap data transformation (array to object)
- Subject allocation extraction
- Phase extraction from monthlyPlan
